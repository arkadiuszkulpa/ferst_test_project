# Ferst Test Project

A [Ferst](https://ferst.co.uk) site — a thin client of the `ferst-core` package.
Content lives in `src/content` (and `src/data/home.json`); edit it in the CMS at
`/admin`, or manage brand + pages in the portal (portal.ferst.co.uk).

```sh
npm install
npm run dev      # local preview
npm run build    # production build (static, to dist/)
```
